⚡ The one new idea in this battle

ListView.builder instead of ListView(children: [...]). In Battle 5, you wrote each item by hand. That's fine for six items. But real apps have hundreds or thousands. ListView.builder is the fix: you store the data in a list, then tell Flutter "build me one row per item."

You'll create a simple data list — a list of chat names, messages, times, and badge counts — and then the builder callback will read each item and turn it into a Row. Same Row you already know. Only the source of the data changes.

The key parameters are itemCount: (how many rows) and itemBuilder: (a function that returns one row given an index). Flutter calls that function once per item.

📎 Shape of the code (skeleton — you fill in the details)

// 1. a plain data class class Chat { final String name; final String message; final String time; final int unread; Chat({required this.name, required this.message, required this.time, this.unread = 0}); } // 2. a list of chat data final chats = [ Chat(name: 'Alice Johnson', message: 'Hey…', time: '9:32', unread: 2), // …five more ]; // 3. inside the Column body, replace the hardcoded rows with: ListView.builder( itemCount: chats.length, itemBuilder: (context, i) { final chat = chats[i]; return /* one Row, same shape as before */; }, )

💡 Battle tip: The trick with ListView.builder is that your row is the same Row you already know — avatar, column of two texts, time block. The only thing that changed is where the data comes from.
