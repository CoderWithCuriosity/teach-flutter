🛠 Your widget toolbox

You may only use these widgets. No others. Everything you need is here.

  • Scaffold Root screen container. Still no AppBar.
  • Column Outer stack: the small header row, then the ListView below it.
  • ListView The new idea. A scrollable vertical list. You give it a children: list of widgets.
  • Row Each dish card is a Row: thumbnail, info column, price.
  • Container The white card, the colored square thumbnail.
  • Text Header title, item count, dish names, descriptions, prices.
  • SizedBox Spacing between widgets and between children in a Row.
  • Padding Inner spacing inside cards and around the body.
  • Icon Six icons — one per dish (ramen, salad, pizza, taco, cake, coffee).

⚡ The one new idea in this battle

A ListView instead of a Column of rows. In Battle 4, you wrote four Rows by hand inside a Column. That works for four items, but not for twenty, and it doesn't scroll.

A ListView is a widget that scrolls on its own. You give it a children: list and it handles the rest. Items that go off-screen just scroll into view.

Important: because the ListView scrolls, the screen can hold more than what fits — so the phone wireframe shows the list slightly cut off at the bottom. That's correct and expected. Try it and scroll.

Still no AppBar. Still no ListView.builder — that comes later. For now, use the simple ListView(children: [...]) form.

💡 Battle tip: Build dish 1 first as a single Container that looks exactly right. Then drop it inside a ListView(children: [ ... ]) and copy it five more times, changing the icon, texts, and price. You don't need to think about scrolling — the ListView does that for you. If it doesn't scroll, your ListView probably isn't getting enough height — check that it's inside a Column that has an Expanded around the ListView, or make sure the Column itself is the direct child of the Scaffold body.
