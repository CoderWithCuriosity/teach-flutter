🛠 Your widget toolbox

You may only use these widgets. No others. Everything you need is here.

  • Scaffold Root screen container. Gives you the white background.
  • AppBar Top bar with the title "Profile".
  • Column Vertical stack — the whole body lives here.
  • Row Horizontal layout — used for the avatar row and the stats row.
  • Container Box with padding, rounded corners, background color.
  • CircleAvatar Round avatar with the letter "A".
  • Text All the labels: name, role, stats, bio, button label.
  • SizedBox Spacing between widgets. Use height: in Column, width: in Row.
  • ElevatedButton The "＋ Follow" button at the bottom.
  • Padding Inner spacing around the whole body.

💡 Battle tip: Don't try to build the whole screen at once. Start with the Scaffold + AppBar. Then add the Column body. Then add ONE child at a time — avatar row first, then stats, then bio, then button. Run flutter run after each step. Hot reload is your best friend.

How the Battle Layout system works

Every "Battle Layout" level in this curriculum follows the same format:

  • One wireframe — a realistic mobile screen with real content, not abstract boxes.
  • A widget toolbox — the exact widgets you're allowed to use. Nothing more.
  • A nesting hint — a tree diagram showing one possible structure. You don't have to match it exactly, only the visual result.
  • No starter code — you run flutter create yourself, open main.dart, and build from zero.
  • Submit when it matches — screenshot the running app next to the wireframe. When they match, the next level unlocks.

As you progress, wireframes get more complex — multiple screens, navigation flows, dynamic data, stateful interactions — but the format stays the same. Read the wireframe, check the toolbox, build it in Flutter.
