🛠 Your widget toolbox

You may only use these widgets. No others. Everything you need is here.

  • Scaffold Root screen container — provides the light background.
  • AppBar Top bar. Put a Row inside its title for the back icon + "Product".
  • Column Vertical stack — the card body, and the info block on the right of the top row.
  • Row The new idea. Top row: image + info column. Bottom row: price + button.
  • Container The white card, the rounded image box, the rating pill.
  • Text Name, category, rating number, description, price.
  • SizedBox Spacing between widgets and between children in a Row or Column.
  • Padding Inner spacing inside the card and around the body.
  • Icon Back arrow, product icon, star icon, cart icon. Use Icon(Icons.xxx).

⚡ The one new idea in this battle

A Column nested inside a Row. In Battle Layout 2 you had a Row whose children were an icon and a text. Now the Row's second child is a Column — three stacked texts (name, category, rating). This is how almost every real product card in the world is built.

On paper it looks like: Row( children: [ image, Column( children: [name, cat, rating] ) ] ). That's the whole new idea.

Also new: the Container for the image needs a fixed width and height so the Row knows how much room to leave for the Column next to it.

📐 Suggested nesting

This is a hint — not the answer. You still have to write every widget yourself.

Scaffold
├─ AppBar // Row: Icon(arrow_back) + "Product"
└─ Padding
   └─ Column // the card
      ├─ Row // ← NEW: image + info
      │  ├─ Container // image (width 90, height 90)
      │  │  └─ Icon(headphones)
      │  ├─ SizedBox(width:14)
      │  └─ Column // ← NEW: nested inside Row
      │      ├─ Text // name
      │      ├─ Text // category
      │      └─ Container // rating pill
      ├─ SizedBox(height:16)
      ├─ Text // description
      ├─ SizedBox(height:16)
      └─ Row // price + button
           ├─ Column // label + value
           └─ Container // Buy button

You don't have to match this tree exactly — any tree that produces the same visual result is correct.

💡 Battle tip: Don't try to build the whole card at once. First build the top row: a Container (image) on the left, a SizedBox(width: 14), and then a Column with three texts on the right. Get that looking right, then move on to the description and the price bar. The whole battle is really just "Row → Column inside it → Row again."
