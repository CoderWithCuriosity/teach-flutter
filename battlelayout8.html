🛠 Your widget toolbox

You may only use these widgets. No others. Everything you need is here.

  • Scaffold Root screen container. Still no AppBar.
  • StatefulWidget The new idea. A widget that can hold changeable state — in this case, one number.
  • setState The other new idea. Tells Flutter "the number changed — please redraw."
  • GestureDetector Wraps each button so it can respond to taps. onTap: runs your code.
  • Column Vertical stack: title, subtitle, counter card, button row.
  • Row Puts the two buttons side by side at the bottom.
  • Container The white counter card, and the two rounded button backgrounds.
  • Text Title, subtitle, "Count" label, the big number, and the button labels.
  • SizedBox Spacing between the widgets.
  • Padding Inner spacing around the whole body.
  • Icon A minus and a plus inside the buttons. Icon(Icons.remove) and Icon(Icons.add).

⚡ The two new ideas in this battle

1. StatefulWidget. Every widget you've written so far is a StatelessWidget — it can't change. A StatefulWidget holds a state object with variables that can change over time. Here, the state is one thing: int count = 0.

2. setState. Inside a StatefulWidget, the only way to change state is to wrap the change in setState(() { ... }). This tells Flutter "something changed — redraw this widget." If you change the variable without setState, the screen does not update. That's the number one beginner mistake.

That's it. One number, two buttons. No lists, no filtering, no data. Just tap → setState → number updates.

📋 Rules of the battle

1 Every widget you use must come from the toolbox above.
2 No AppBar. The Scaffold only has a body:.
3 The screen must be a StatefulWidget — not a stateless one.
4 Tapping a button must call setState. Never change the count without it.
5 No lists. No data. Just one number and two buttons.
6 Match the wireframe visually — same colors, same shapes.
7 Start the counter at 7 (not 0), to match the wireframe.

import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Tap Counter',
      debugShowCheckedModeBanner: false,
      home: const CounterScreen(),
    );
  }
}

class CounterScreen extends StatefulWidget {
  const CounterScreen({super.key});
  @override
  State<CounterScreen> createState() => _CounterScreenState();
}

class _CounterScreenState extends State<CounterScreen> {
  int count = 7;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: const Color(0xFFF4F6FB),
      body: SafeArea(
        child: Padding(
          padding: const EdgeInsets.symmetric(horizontal: 18, vertical: 24),
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              const Text(
                'Tap Counter',
                style: TextStyle(
                  fontSize: 20,
                  fontWeight: FontWeight.bold,
                  color: Color(0xFF1A1D26),
                ),
              ),
              const SizedBox(height: 6),
              const Text(
                'Use the buttons below',
                style: TextStyle(
                  fontSize: 14,
                  color: Color(0xFF68708A),
                ),
              ),
              const SizedBox(height: 26),
              Container(
                width: double.infinity,
                padding: const EdgeInsets.symmetric(vertical: 36, horizontal: 24),
                decoration: BoxDecoration(
                  color: Colors.white,
                  borderRadius: BorderRadius.circular(20),
                  boxShadow: [
                    BoxShadow(
                      color: Colors.black.withOpacity(0.06),
                      blurRadius: 24,
                      offset: const Offset(0, 6),
                    ),
                  ],
                ),
                child: Column(
                  children: [
                    const Text(
                      'COUNT',
                      style: TextStyle(
                        fontSize: 12,
                        color: Color(0xFF68708A),
                        letterSpacing: 1.2,
                      ),
                    ),
                    const SizedBox(height: 10),
                    Text(
                      '$count',
                      style: const TextStyle(
                        fontSize: 64,
                        fontWeight: FontWeight.bold,
                        color: Color(0xFF1A1D26),
                        fontFamily: 'monospace',
                      ),
                    ),
                  ],
                ),
              ),
              const SizedBox(height: 20),
              Row(
                children: [
                  Expanded(
                    child: GestureDetector(
                      onTap: () => setState(() => count--),
                      child: Container(
                        height: 60,
                        decoration: BoxDecoration(
                          color: const Color(0xFFFCE4EC),
                          borderRadius: BorderRadius.circular(14),
                        ),
                        child: Row(
                          mainAxisAlignment: MainAxisAlignment.center,
                          children: const [
                            Icon(Icons.remove, color: Color(0xFFC2185B)),
                            SizedBox(width: 8),
                            Text(
                              'Minus',
                              style: TextStyle(
                                fontWeight: FontWeight.bold,
                                color: Color(0xFFC2185B),
                              ),
                            ),
                          ],
                        ),
                      ),
                    ),
                  ),
                  const SizedBox(width: 12),
                  Expanded(
                    child: GestureDetector(
                      onTap: () => setState(() => count++),
                      child: Container(
                        height: 60,
                        decoration: BoxDecoration(
                          color: const Color(0xFF69F0AE),
                          borderRadius: BorderRadius.circular(14),
                          boxShadow: [
                            BoxShadow(
                              color: const Color(0xFF69F0AE).withOpacity(0.35),
                              blurRadius: 16,
                              offset: const Offset(0, 6),
                            ),
                          ],
                        ),
                        child: Row(
                          mainAxisAlignment: MainAxisAlignment.center,
                          children: const [
                            Icon(Icons.add, color: Color(0xFF0A0D13)),
                            SizedBox(width: 8),
                            Text(
                              'Plus',
                              style: TextStyle(
                                fontWeight: FontWeight.bold,
                                color: Color(0xFF0A0D13),
                              ),
                            ),
                          ],
                        ),
                      ),
                    ),
                  ),
                ],
              ),
            ],
          ),
        ),
      ),
    );
  }
}
