🛠 Your widget toolbox

You may only use these widgets. No others. Everything you need is here.

  • Scaffold Root screen container — provides the light background.
  • AppBar Top bar. Put a Row inside its title to hold the back icon and the word "Contact".
  • Column Vertical stack — the whole card lives inside one.
  • Row The new idea. Puts an icon and text side by side in each detail row.
  • Container The white card, the avatar circle, and the little icon circles.
  • Text Name, role, and the detail text next to each icon.
  • SizedBox Spacing between widgets and between children in a Row.
  • Padding Inner spacing inside the card and around the body.
  • Icon The back arrow, the email icon, the phone icon. Use Icon(Icons.xxx) — never emoji.

⚡ The one new idea in this battle

A Row with an Icon and a Text. You already know how to stack things vertically with a Column. Now you'll put two things side by side using a Row: an icon on the left, some text on the right. That's how the two detail rows in the card are built.

And remember: in Flutter you never type emoji. You type Icon(Icons.email), Icon(Icons.phone), Icon(Icons.arrow_back). Icons are widgets — they take a size and a color.
