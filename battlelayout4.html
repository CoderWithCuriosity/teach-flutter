🛠 Your widget toolbox

You may only use these widgets. No others. Everything you need is here.

  • Scaffold Root screen container. No AppBar this time — leave that argument out entirely.
  • Column The main vertical stack: header on top, list of rows below it.
  • Row The repeating idea. Each transaction row is a Row with three children: icon, info column, amount.
  • Container The white card behind each row, and the little colored icon square on the left.
  • Text Section title, "See all", row titles, row subtitles, amounts.
  • SizedBox Spacing between widgets and between children in a Row.
  • Padding Inner spacing inside each row card and around the body.
  • Icon The chevron in "See all", and the four icons in the rows (payments, cart, refresh, card).

⚡ The one new idea in this battle

A list built from a Column of Rows. There's no ListView yet — that comes later. For now, you just stack four Rows inside one Column, separated by SizedBox(height: 10). Same row structure, repeated four times.

Each row is itself a nested structure: Row( children: [ iconContainer, SizedBox, Column(title, subtitle), amountText ] ). That's the whole pattern. Four copies of the same pattern.

Also different: no AppBar. The Scaffold only has a body. That's fine — that's the whole point of this battle. You're learning to build a screen without the top bar.

📐 Suggested nesting

This is a hint — not the answer. You still have to write every widget yourself.

Scaffold // no AppBar
└─ Padding
   └─ Column
      ├─ Row // section header
      │  ├─ Text // "Recent"
      │  └─ Row // "See all" + Icon(chevron_right)
      ├─ SizedBox(height:14)
      ├─ Row // ← row 1
      │  ├─ Container // icon square
      │  ├─ SizedBox(width:12)
      │  ├─ Column // title + subtitle
      │  └─ Text // amount
      ├─ SizedBox(height:10)
      ├─ Row // ← row 2 (same shape)
      ├─ SizedBox(height:10)
      ├─ Row // ← row 3
      ├─ SizedBox(height:10)
      └─ Row // ← row 4

You don't have to match this tree exactly — any tree that produces the same visual result is correct.

📋 Rules of the battle

1 Every widget you use must come from the toolbox above.

3 Match the wireframe visually — same spacing, same card shape, same colors.
